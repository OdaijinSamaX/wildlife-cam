# 蝶ねじの捕捉 — 落としたら二度と見つからないねじを、どう蓋に残すか

- 日付: 2026-08-23
- 対象: `designs/wildlife_cam/camera_unit_lid.py` / `camera_unit.py`
- 実装: 蓋のシール面側に**捕捉ポケット**（φ9.8 / φ11.8 x 深さ 10.5）を彫り、
  軸に付けたリテーナで受け止める。`captive` チェックを新設（**12 個目**）
- 決定: `docs/DECISIONS.md` **D-020**
- 出発点: `docs/field-procedure.md` C-3 の宿題「E リングか段付きねじで捕捉する構造。**未設計（6 本ぶん）**」

---

## 0. 結論

**採ったのは「蓋の内側に捕捉ポケットを彫り、軸に平たいリテーナを 1 個付ける」。**
リテーナは **E 形止め輪（JIS B 2805）呼び 4 / 呼び 5**、または**同じ外径に収まる
押しナット（プッシュナット）**のどちらでもよい。**蓋の形はどちらでも同じ**である。

| | 値 | 出所 |
|---|---|---|
| 蝶ボルト | **M4 x 30**（1 本だけ M5 x 30） | JIS B 1184。国内で普通に買える |
| リテーナ外径 | 9.0 / 11.0 mm | E 形止め輪 呼び4 / 呼び5 の外径（**推定・要確認**） |
| ポケット | φ9.8 / φ11.8 x 深さ **10.5** | 設計値 |
| ねじが後退できる量 `travel` | **9.7 mm** | 10.5 − リテーナ厚 0.8 |
| 噛み合い `engage` | **8.0 mm**（= 呼び径の 2 倍） | 30 − 蓋 19 − 隙間 3 |
| 緩めきったときの出しろ | **1.3 mm** < 隙間 3.0 mm | 蓋を平らに置ける |
| **最小圧縮率（`seal`）** | **21.0%（変わらず）** | ポケットを彫る前と同じ |

**面圧は落ちていない。** ポケットの深さを 4.5 → 10.5 mm に変えても最小圧縮率は
20.98% → 20.97% しか動かない。**捕捉ポケットは締結点の真上、つまり梁のたわみが
拘束されている場所にある**ので、断面が痩せても中央の浮きにはほとんど効かない。

## 1. 要件（外すと不合格）

1. **蓋を外したとき蝶ねじ 6 本が蓋に付いたまま残る**（AGENTS.md §4.9 原則 1）
2. **手袋をした手で回せる**（工具なし。原則 6）
3. 面圧が落ちない（`seal` で確認する）
4. 造形姿勢 `rotate (90,0,0)` とサポート不要を維持する
5. 外形 84 x 50 x 198 と幹からの張り出しを増やさない
6. **国内で普通に買える**部品で組める

## 2. 効いた制約は「パッキン溝までの距離」だった

検討を始める前は「どの止め方が確実か」が主題だと思っていたが、
**実際に案を絞ったのは寸法の方**である。

```
締結点  x = ±31（M5 の 1 本だけ x = -30）
パッキン溝の内縁  x = 37.65
残せる肉  min_wall 1.6 mm
  -> ポケットの半径の上限 = 37.65 - 31 - 1.6 = 5.05
  -> **ポケット径の上限 φ10.1、リテーナ外径の上限 φ9.3**
```

**外径 9.3 mm を超えるリテーナは、そもそも入らない。**
市販の平型スピードナット（M4 で外径 14 前後）はこの時点で落ちる。
E 形止め輪 呼び 4 の外径 9.0 はぎりぎり入る。
締結点の x を内側へ寄せれば余裕は出るが、**x = ±31 は D-019 で決まっている**
（座ぐりをパッキン溝から 2 mm 以上離すため）ので動かさない。

M5 の 1 本は x = -30（ポカヨケで 1 mm 内側）なので上限が φ12.1 まで緩み、
E 形 呼び 5 の外径 11.0 が入る。**ポカヨケのためのずらしが、たまたま効いた。**

## 4. 採用した形（寸法の連鎖）

```
   y=0 シール面                                          y=22 鞍の面
     |                                                      |
     |<-- 捕捉ポケット -->|<------ 通し穴 ------>|<- 座ぐり ->|
     |   φ9.8 / 10.5      |        φ4.5          | φ9.0 / 3.0 |
     |                                                      |
     |<---------------- T = 19.0 --------------->|  頭の座面
     |<- 隙間 3.0 ->| 柱の天面（インサート φ4 x 8）
     |<---------- tip_depth = 11.0 ---------->|
                    |<- engage = 8.0 ->|
```

**組立の決めごと**: 蝶ねじを外側から通し、頭を座ぐりに密着させたまま、
**リテーナをシール面と面一になるまで押し込む**。
（蓋をシール面を下にして平らな台に置き、突き当たるまで押せばよい。ゲージは要らない。）

これで `travel`（ねじが後退できる量）が **ポケットの深さ − リテーナの厚み** に
固定される。**組立者の腕に依存しない**のがこの形の要点である。

### 4.1 成立の窓

`travel` には上下から挟む条件が付く。

```
下限: travel >= engage + 余裕      = 8.0 + 1.0 = 9.0    …これを割ると【蓋が開かない】
上限: travel >  tip_depth - 隙間   = 11.0 - 3.0 = 8.0   …これを割ると【蓋を平らに置けない】
実際: travel = 10.5 - 0.8          = 9.7               ✓
```

**窓は 9.0 〜（上限なし。ただし深くすると蓋が痩せる）。** 9.7 は下限から 0.7 mm。
ねじの実長のばらつき（±0.5 mm 程度）を考えると余裕は大きくないので、
**実機で 1 本組んで確かめること**（§7）。

### 4.2 なぜ「緩めきってもねじ先が 1.3 mm 出ている」のがよいのか

隙間 3.0 mm より短いので、**蓋を本体に平らに置いてから 1 本ずつ回し始められる。**
6 本の先端が同時にインサートを探す必要がない。
逆に出しろが隙間を超えると、蓋を置いた時点で先端が柱の天面を突き、
**蓋が傾いてパッキンが片当たりする。** `captive` の条件 5 はこれを見ている。

### 4.3 なぜ M4 x 30 か（M4 x 25 ではなく）

| | M4 x 25 | **M4 x 30（採用）** |
|---|---|---|
| 噛み合い | 3.0 mm（呼び径の 0.75 倍） | **8.0 mm（2 倍）** |
| 必要なポケット深さ | 4.5 mm | 10.5 mm |
| `seal` 最小圧縮率 | 20.98% | **20.97%** |

**ポケットを 6 mm 深く彫っても面圧が 0.01 ポイントしか動かない**ことが分かったので、
噛み合いの厚い方を採った。ポケットは締結点の真上にあり、そこは梁のたわみが
拘束されている場所なので、断面が痩せても中央の浮きに効かない（`seal` が実測した）。

**副作用として本体を 1 箇所直した。** M4 x 30 はインサート（深さ 8）を使い切るので、
下穴がインサートと同じ深さだと**先端が底を突いて締めたつもりで面圧が出ない**。
`lid_pilot_depth` を新設し、下穴を 12 mm（インサート 8 + 逃げ 4）にした。

## 5. 造形（サポートは要らないまま）

捕捉ポケットは**シール面 = 第 1 層に開く**ので、天井が下向き面になる。

```
天井は 内径 φ4.5 / 外径 φ9.8 の環  ->  渡す幅 = (9.8 - 4.5) / 2 = 2.65 mm
```

`overhang` は下向きパッチの **XY 投影の最大内接円**で渡り幅を測るので、
環の場合はバウンディングボックスの 9.8 ではなく **2.65 mm** と出る。
ブリッジ可の閾値 10 mm を大きく下回るのでサポートは要らない
（チェックの結果も「span 10 mm 以下でブリッジ可」の WARN のまま変わっていない）。

**ポケットはパッキン溝の内側にある**ので、漏れ経路にはならない。
`openings` の貫通開口は 6 箇所・103.26 mm2 のまま（通し穴の径は変えていない）。

## 6. 不採用にした案の理由（同じ検討を二度やらないため）

### 6.1 案 C: ばね + キャプティブナット — **寸法が入らない**

頭の下にばねを入れて、緩めたときにねじを引っ込めておく案。**考え方は良い**が、

```
ばねが縮む前の自由長 >= travel 9.7 mm ぶんの行程が要る
ばねを置ける場所 = 頭の座ぐり 3.0 mm しかない
```

**3 mm の座ぐりに 9.7 mm 動くばねは入らない。** 座ぐりを深くすると蝶の羽根が
沈んで手袋で摘めなくなる（要件 2）。柱と蓋の隙間（3 mm）に入れる手もあるが、
そこにばねを置くと**蓋を本体から押し離す向きに働いてパッキンの面圧と喧嘩する。**

### 6.2 案 E: 首に O リングを嵌める — **回すたびに歩いて外れる**

ゴムの O リング（内径 3 / 線径 1.5）を軸に転がして通す案。加工が要らず安く、
材料も手元にある。**しかし、これは軸方向の止めではなく摩擦の止めである。**

ねじを緩める向きに回すと、リテーナは蓋の面に押し付けられて回転が止まり、
**ねじだけが回る**。右ねじなのでリテーナはねじに対して相対的に先端側へ進む
（＝頭から遠ざかる）。**緩めるたびに O リングは先端へ歩き、いずれ抜け落ちる。**
これは「ねじ込み式のナット + ねじロック」でも同じ向きに起きる。

**止め輪と押しナットにはこの失敗が無い。** どちらもねじ山に噛んでいないので、
押し付けられたまま**空回りするだけで移動しない。** ここが形式の分かれ目である。

> `captive` チェックは**この失敗を見ていない**（寸法の連鎖しか見ない）。
> 形式の選択で避けるしかないので、ここに書いて残す。

### 6.3 案 F: 印刷したスナップ爪で軸を掴む — **ねじ山が爪を切って抜ける**

蓋と一体で弾性の爪を印刷し、軸を掴ませる案。部品が増えないのが魅力だが、

- 爪が噛むのはねじ山の谷。**回せばねじ自身が爪をねじ切って抜けていく**（案 E と同じ理屈）
- ASA は屋外で**クリープする**。数ヶ月押し付けられた爪は開いたまま戻らない
- 爪はシール面側（第 1 層）に立つので、**摺動面が積層の段差そのもの**になる

### 6.4 案 G: 蓋側にもインサートを入れる — **原理的に捕捉できない**

蓋にもヒートセットインサートを入れ、ねじが常に蓋のねじに噛んでいるようにする案。
**ねじは回せば必ず抜けるので、そもそも捕捉ではない。**
捕捉には「ねじ山ではない軸方向の当たり」が要る、という一般則の確認として残す。

### 6.5 案 H: 本体側に植込みボルト + 蝶ナット — **落とす部品が蝶ナットに変わるだけ**

本体の柱に植込みボルトを立て、外から蝶ナットで締める案。
**蓋が 6 本のボルトで自動的に芯出しされる**のは大きな利点で、
案 A/B の「先端 1.3 mm で探す」より現地は楽になる。しかし、

- **蝶ナットは完全に外れる。** 落とす部品がねじからナットに変わっただけで、要件 1 を満たさない
- ナットを蓋側に捕捉するには、蓋を 2 部品にするか、回転を許して軸方向だけ止める
  受けが要る。**印刷 1 部品では作れない**
- 6 本のボルトが背面から 11 mm 突き出したままになり、蓋を外した本体が扱いにくい

**実機で「先端で探すのが辛い」となったら、ここを読み直すこと。**

## 7. 実機で確かめること（計算では出せない）

1. **リテーナの型番と実寸。** 外径 9.0 / 11.0 は**推定**である。
   9.3 mm を超えるとパッキン溝までの肉が 1.6 mm を切る。**買う前にノギスで測ること**
2. **`travel` の余裕 0.7 mm。** 蝶ボルトの実長のばらつき（±0.5 mm 程度）と、
   ヒートセットインサートの座面が沈む / 飛び出す量が効く。
   **1 本組んで「緩めきったときにねじ先が引っ込むか」を目で見ること**
3. **リテーナの保持力。** 何 N で抜けるかはカタログ値も実測も入れていない。
   蓋をぶら下げて（蓋 + ドームで 300 g 程度）ねじ 1 本で保てるかを見ること
4. **手袋をした手で回せるか。** M4 の蝶ボルトの羽根は幅 20 mm 前後（**推定**）。
   座ぐり 3 mm に頭が沈むので、羽根は面から 1.5 mm ほどしか出ない見込み。
   **辛ければ座ぐりを浅くする**（浅くすると噛み合いが減るので `captive` を回し直す）
