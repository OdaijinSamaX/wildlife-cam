- 日付: 2026-08-22
- 実装: `designs/wildlife_cam/window_snoot.py`（案S・主案）/ `window_hood.py`（案H）
- 部品: `parts/dome_lid.py` / `parts/cam_module3.py`

## 1. 視野の計算と、そこから出る形の制約

### 1.1 レンズ諸元（**要検証**）

| 項目 | 値 | 出所 |
|---|---|---|
| 焦点距離 | 4.74 mm | 公表値とされる数字。**実機で測っていない** |
| センサ対角 | 約 7.4 mm | 同上 |
| 水平画角 | 約 66 度 | 同上 |
| 垂直画角 | 約 41 度 | 同上 |
| 対角画角 | 約 75 度 | 同上 |

判定には焦点距離とセンサ対角から導出した値を使う。

```
半角 = atan((7.4 / 2) / 4.74) = 37.98 度   ->  対角 75.95 度
```

公表の「約 75 度」（半角 37.5）とほぼ一致するので矛盾は無い。導出値の方が
0.5 度広いので、そちらを採る（判定が安全側に倒れる）。
`parts/cam_module3.FOCAL_LENGTH_MM` などで**パラメータ化してある**ので、
実測が入れば全設計の判定が自動で追随する。

### 1.2 帰結: 細長い筒は成立しない

内半径 r・長さ L の**真っ直ぐな筒**が視野を遮らない条件は

```
L < r / tan(半角) = r / 0.7806 = 1.281 r
```

| 内半径 r | 真っ直ぐな筒の上限 L |
|---|---|
| 10 mm | 12.8 mm |
| 15 mm | 19.2 mm |
| 20 mm | 25.6 mm |

**φ20 の筒なら 12.8 mm しか伸ばせない。** 防犯カメラの筒が長いのは望遠寄りで
視野が狭いからで、対角 76 度のこの構成では同じ形にはできない。
**短くて末広がりの形にしかならない。**

（公表値の 75 度・半角 37.5 で計算すると `L < 1.303 r`。結論は変わらない。）

### 1.3 計算が実物を説明した

現行機は**タッパーに穴を開け、透明な食品用カップを嵌めて、隙間を瞬間接着剤で
埋めていた**。この構成で比較的綺麗な映像が撮れているという実地の実績がある。

その透明カップは **短くて末広がり**の形をしている。上の計算が「そうなるしかない」
と言った形と一致する。**計算が、先に存在していた実物を説明した。**

この収束には 2 つの意味がある。

- **案S（筒）の方向には実地の裏付けがある。** 主案として進めてよい。
- 視野の計算とレンズ諸元が、少なくとも大きくは間違っていない。

したがって作り直すべきは**光学ではなく耐久性**である（次節）。

## 2. 既製品のドーム蓋（主案の窓）

実物が確定した。**ドリンク用の透明ドーム蓋。**

| 項目 | 実測 2026-08-22 |
|---|---|
| 口径（縁の径） | 76.0 mm |
| 深さ | 32.2 mm |
| **頂点の平らな窓** | **φ25.0 mm** |
| 肉厚 | 0.4 mm |

**頂点の φ25 は穴ではなく塞がった平面。** 光は平面を通るので像が歪まない。
曲面越しに撮るのではない。試作機ではドームが外に出る向きで取り付け、
カメラはドームの中に入っていた。

### 2.1 レンズは平窓から 16.0 mm 以内

```
L_max = (25.0 / 2) / tan(37.98 度) = 16.01 mm
```

**フランジ位置（32.2 mm 奥）では半角 21.2 度（対角 42.4 度）しかなく、
四隅が大きく欠ける。** そこで前壁から筒を伸ばしてカメラを 16 mm 圏内へ
送り出す。防犯カメラと同じ作り。

`designs/wildlife_cam/window_snoot.py` では

```
レンズ前面 z = 26.6 / 平窓 z = 40.2  ->  距離 13.6 mm（上限 16.01、余裕 2.41）
実際に得られる半角 42.59 度（必要 37.98 度）
```

**`fov` チェックが機械的に検証する。** ドームの平窓の外側（= 像として使えない
曲面部）を `dome apex ring` という部品として置いてあり、視野円錐がそこに
掛かった瞬間に FAIL する。カメラを後ろに下げれば必ず落ちる。

> 円錐の頂点はレンズ前面に置いている。実際の入射瞳はそれより後ろにあるので、
> 真の要求はもう少し厳しい。`window_snoot.PUPIL_DEPTH_MM` に入れれば判定が
> 自動で厳しくなる。いまの余裕 2.41 mm は、瞳が前面より 2.41 mm 後ろまでなら
> 成立するという意味でもある。

## 3. 作り直すべきは光学ではなく耐久性

現行機の弱点は形ではなく材料と接着である。

| 現行機 | 問題 |
|---|---|
| 食品用カップ（PET / PP） | **紫外線で数ヶ月で白濁し脆化する** |
| 瞬間接着剤（シアノアクリレート） | **硬く脆い。** 温度変化と振動で微細に割れ、そこから浸水する |

**同じ形状を、耐候性のある材料と弾性のあるシールで作り直すのが設計の目的。**

- 硬い接着剤 -> **弾性のある O リング**（潰し代で追従する）
- 使い捨ての食品容器 -> **交換前提の消耗品として設計に組み込む**

## 4. 窓の材料

### 4.1 前提: 窓は印刷できない

透明フィラメントで刷っても**層の線で曇る**（層間の界面が光を散乱する）。
**買った平板・成型品を嵌める前提**にする。

### 4.2 必須条件: 850 nm の近赤外を透過すること

IR 投光器が 850 nm なので、**IR カットフィルタは使えない**。
市販の「カメラ用窓」には IR カットコートが載っているものがあるので注意する。

### 4.3 材料の比較

| | アクリル (PMMA) | ポリカーボネート (PC) | ガラス | PET（現行のドーム蓋） |
|---|---|---|---|---|
| 850 nm 透過 | 良好（約 92%） | 良好（約 88%） | 良好 | **良好** |
| **屋外の紫外線劣化** | **非常に強い。**屋外看板の標準材 | **弱い。** 数年で黄変（UV 安定グレードなら改善） | **不変** | **弱い。数ヶ月で白濁** |
| 傷 | 中（PC より硬い） | **弱い。**柔らかく擦り傷が付く | **非常に強い** | 弱い |
| 光学性能 | 良好・複屈折が小さい | 複屈折がある | **最良** | 成型品なので個体差あり |
| 耐衝撃 | 割れやすい | **最強** | 割れる・破片が危険 | 薄いので割れる |
| 質量 | 軽い（比重 1.19） | 軽い（1.20） | **重い（2.5）** | 軽い |
| 入手（カップ形状） | **防犯カメラ用アクリルドームがある** | ドームは入手しにくい | 平板のみ | 安価・どこでも |

### 4.4 推奨

**平板を使うなら アクリル（PMMA・キャスト材）。**

理由を効く順に。

1. **屋外の紫外線に対して圧倒的に強い。** PC は数年で黄変する。この装置は
   屋外に置きっぱなしなので、UV 劣化が寿命を決める。
2. **軽い。** 設置先が細くしなる木なので、ガラスの比重 2.5 は不利
   （`docs/layout-study.md` の取り付け評価を参照）。
3. 850 nm を素通しする。
4. 傷は PC より付きにくい。

PC を選ぶのは**耐衝撃が支配的なリスク**のときだけで、その場合も UV 安定グレードを
指定する。ガラスは光学と耐傷は最良だが、重さと破片の危険で不採用。

**カップ形状を使うなら、防犯カメラ用のアクリルドームが本命。**
現行の PET ドーム蓋と同じ形で、UV に強い。ただし入手性と寸法の自由度は落ちる。

### 4.5 平板 vs カップ（ドーム）

| | 平板 | カップ / ドーム |
|---|---|---|
| 雨粒 | 前面に留まりやすい。庇が要る | **上面が曲面なので自然に流れ落ちる** |
| 視野 | 開口を末広がりに彫る必要がある | **視野を遮らない**（頂点の平窓を通す） |
| 実績 | 無し | **現行機で実用的な映像が撮れている** |
| 入手性 | 任意の径・厚みが手に入る | 既製品のサイズに縛られる |
| 寸法の自由度 | **高い** | 低い。深さ 32.2 が設計を支配する |
| 交換 | 接着なら交換しにくい | **嵌合式なら工具なしで交換できる** |
| 割れたとき | 平板だけ交換 | ドームだけ交換 |
| 箱の奥行き | 薄くできる | カメラを 16 mm 送り出すぶん厚くなる |

**主案はカップ（ドーム）。** 実績と雨粒の流れ落ちが効く。
平板は「ドームの入手が途切れたときの代替」として `window_hood.py` に残す。

### 4.6 PET ドーム蓋の交換周期の目安

肉厚 0.4 mm の PET は屋外の紫外線で白濁・脆化する。
**目安として 3 〜 6 ヶ月に 1 回、点検して交換する。**

- 判断基準: 光にかざして曇りが見えたら交換。指で押して「パキッ」と音が
  するようになったら脆化が進んでいるので即交換。
- 実測の裏付けは無い（現行機の実績からの推定）。**最初の 1 年は毎回の
  巡回で状態を記録し、実際の劣化速度を掴むこと。**
- アクリルドームに替えれば数年に伸びる見込み。ただしこれも未検証。

## 5. ドームの保持と、割れたときの被害の閉じ込め

### 5.1 保持は既製品の嵌合に任せる

ドーム蓋には**カップの縁に嵌まる溝が元から成形されている**。筐体側に
カップ縁と同形状のリブを印刷すれば、ドームが設計どおり嵌合する。

- **工具なしで着脱できる**（現地保守の原則。`docs/AGENTS.md` §9）
- 傷んだら買って交換できる
- **保持は嵌合、防水はその下の O リング**、という役割分担

### 5.2 嵌合部の未実測項目（実測が来たら差し替える）

`parts/dome_lid.UNMEASURED` に列挙してある。**7 項目。**

1. 嵌合溝の内径（カップ縁の外径に相当）
2. 嵌合溝の深さ（半径方向の食い込み量）
3. 嵌合溝の高さ（軸方向の幅）
4. 溝の入口から蓋の縁までの距離
5. 縁の肉厚（溝の外側の壁）
6. 抜け止めビードの有無と、あればその断面寸法
7. 嵌合の締め代（カップ縁との干渉量）

いまのリブ寸法（外径 75.4 / 立ち上がり 6.0 / ビード 0.6）は**すべて推定**。

### 5.3 ドームは消耗品。割れても本体を水没させない

肉厚 0.4 mm は変更できない。**割れる前提で設計する。**

密閉境界を 2 段にする。

```
1 段目  ドーム + O リング        -> カメラ室（送り出し筒の中）を密閉
2 段目  筐体の前壁 + FPC 貫通の封止 -> **本体（Pi / Onyx）を守る**
```

FPC は取付板の φ8 のポートを通し、シーラントで埋める。ここが 2 段目の境界。

**ドームが割れるとカメラ室（約 90 cm3）は浸水するが、本体は乾いたまま残る。**
現地ではドームとカメラを交換すれば復帰できる。カメラ（約 4 g・安価）を
ドームと同じ「消耗側」に置いたのは意図的な割り切りである。

## 6. 庇（案H の知見）を合流させる

`window_hood.py`（平板 + 庇）で得た知見をドーム案に持ち込むかどうか。

### 6.1 庇の張り出しには上限がある

視野円錐は前へ行くほど太るので、庇も無限には伸ばせない。

```
庇を高さ y に置くとき、前端の上限 z = y / tan(37.98 度) + レンズ前面の z
```

ドーム案（レンズ前面 z=26.6）でドームの外（y=40 mm）に庇を置くなら、
**前端は z=77.8 まで**。ドーム頂点 z=40.2 より 37.6 mm 先まで出せる。
つまり庇は**幾何学的には成立する**。

### 6.2 それでも既定では付けない

| 庇が効くもの | ドームで既に足りているか |
|---|---|
| 雨粒が窓に留まるのを防ぐ | **足りている。** ドーム上面の曲面が水を流す。実地の実績あり |
| 直射光のフレアを遮る | 部分的に足りない。ドームは遮光しない |
| 窓の汚れ | 足りている（流れ落ちる） |

一方でコストがある。

- **受風面積が増える。** 設置先は細くしなる木で、風荷重が効く
- 部品点数が増え、界面（＝壊れる場所）が増える
- ドームの着脱に干渉しないよう避ける必要がある

**結論: 既定では付けない。** 現地でフレアが実際に問題になったら、
`window_snoot.max_hood_projection()` で寸法を出して後付けする。
**判断を先送りできる形にしてある**（庇は独立部品として後から足せる）。

## 7. 2 案の比較（まとめ）

| 比較軸 | 案H（平板 + 庇） | 案S（ドーム）**主案** |
|---|---|---|
| 雨粒が窓に付きにくいか | 庇で防ぐ。庇の下に留まることはある | **上面の曲面が流す。実績あり** |
| 直射光のフレア | **庇で遮れる** | 遮れない（必要なら庇を後付け） |
| 造形姿勢とサポート | 光軸を造形方向に平行。**サポート不要** | 同左。**サポート不要** |
| 部品点数 | 板 + 庇（一体）+ 平板窓 + O リング | 板 + ドーム（既製品）+ O リング x2 |
| 外観の目立ちにくさ | 平たく目立ちにくい | **突き出るので目立つ** |
| 交換のしやすさ | 平板が接着だと交換しにくい | **工具なしで着脱** |
| 箱の奥行き | 薄い | **カメラ送り出しぶん厚い** |
| 実地の裏付け | 無し | **あり** |
| 窓の入手 | 任意サイズのアクリル板 | 既製品のサイズに縛られる |

**主案は案S。** 実績・雨・交換性で勝ち、負けているのは「目立つ」と「厚い」だけ。
案H は、ドームの入手が途切れたときの代替として残す。
