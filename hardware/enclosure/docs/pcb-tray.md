## 0. 結論

**z 方向のスライドレール（アリ溝）は成立しない。**
D-019 で蓋の締結を 6 点にしたとき、内部に 6 本の柱が立った。その柱が
**Pi を載せたトレーの通り道を塞いでいる。**

代わりに **背面（開口側）から差し込み、棚に載せ、クリックで止める** 形にした。
併せて **旧レールの押し出し方向の不具合**（宣言 z 128〜194 に対し実物が z 62〜128）
も直した — というより、レールごと作り直した。

| | 値 |
|---|---|
| トレーの外形 | 72.4 x 12.5 x 28.9 mm（造形姿勢後） |
| 載せるもの | Raspberry Pi Zero 2 W（M2.5 x 4 本） |
| 差し込み方向 | **+Y から -Y**（背面の開口から） |
| 保持 | 棚（-Z）/ 上の押さえ（+Z）/ 側壁とリップ（±X）/ 前の当たり（-Y）/ **クリック止め（+Y）** |
| ポカヨケ | **-X 側の棚だけ 2.5 mm 高い**（3 通りの反転をすべて物理的に止める） |

---

## 1. なぜアリ溝が成立しないのか（2 つの独立した理由）

### 1.1 柱が Pi の通り道を塞ぐ

```
蓋の柱の x    26.9 〜 35.1（φ8.2）/ 25.3 〜 34.7（φ9.4 の 1 本）
内側に残る幅  2 x 26.9 = 53.8 mm
Pi Zero 2 W   65.0 mm            ->  **柱の z を通り抜けられない**
```

アリ溝は**端から差し込むしかない**。トレーがレールに乗るには柱の z を
通過しなければならないが、**幅 65 mm の Pi は物理的に通れない。**

柱の影のない z の窓は **146.1 〜 181.3 = 35.2 mm** しかなく、Pi の丈 30 mm を
置くと**動かせるのは 5.2 mm**。アリ溝の掛かり代にも足りない。

### 1.2 背面の開口が側壁より狭い

```
側壁の内面        x ±39
合わせ面の land   x 37 〜 42（リムの段 rim_step 2.0 のぶん内側へ張り出す）
**背面の開口**    **x ±37**
```

**側壁に付けたアリ溝に届く幅のトレーは、そもそも背面の開口を通れない。**
箱を組むとき最後に入るのはトレーなので、これは致命的である。

> **この 2 つはどちらも「レールを短くする」では解けない。** 指示にあった
> 「柱を避けた形にする」を素直にやると、レール方式そのものが落ちる。

## 2. 採った形

```
        z
        ^         ┌──── 上の押さえ (z 178.1〜179.7, x 34.5〜39)
        |         │        遊び 1.2 mm
        |    ┌────┴──────────────────────┐
        |    │   板 (y 23.9〜26.4)        │   <- Pi はこの上（+Y 側）
        |    │   ボス 4 本 + 掴みタブ 2 枚 │
        |    └────┬──────────────────────┘
        |         │  位置決めリップ (x 36.6〜39, 高さ 1.5)
        |    ═════╧══════ 棚 (x 34.5〜39)  <- クリックの切り欠きはここ
        +------------------------------------> x
```

| 向き | 何が受けるか |
|---|---|
| -Z（落下） | **棚**の天面。トレーの自重はここが持つ |
| +Z（浮き） | **上の押さえ**（遊び 1.2 mm。クリックの歯 0.8 が乗り越えるぶん） |
| ±X | **位置決めリップ**（片側 0.4 mm）。側壁との 2.8 mm ではガタが大きすぎる |
| -Y | **前の当たり** |
| **+Y（抜け）** | **クリック止めの歯**（蓋を開けているとき）/ **蓋**（閉めているとき） |

### 2.1 クリック止めの本当の仕事

**蓋が閉まっていれば +Y は蓋が塞ぐ。** だからクリック止めの仕事は
**「蓋を開けて作業している間にトレーが落ちないこと」**である。
屋久島の林床に基板を落とさないための最小限の機構、という位置づけ
（`docs/AGENTS.md` §4.9.3-1「位置決めはスライド、抜け止めは別に最小限」）。

棚の天面に **45 度フランクの切り欠き**（深さ 0.8）、トレーの下縁に**同じ形の歯**。
差し込むときは歯が棚に乗り上げ、home で落ちて鳴る。
引き出すときは **指で 0.8 mm 持ち上げながら手前に引く。工具は要らない。**

**「効いていること」と「外せること」を両方テストにしてある**（片方だけなら、
ただの隙間か、ただの嵌め殺しでしかない）:

  - `test_the_detent_actually_blocks_the_tray_from_backing_out`
    … home のまま +Y へ 0.5 / 1.0 / 2.0 mm 動かすと**必ず当たる**
  - `test_tray_can_be_pushed_in_from_the_back`
    … 0.8 mm 持ち上げれば 18 mm の経路が**全部通る**

### 2.2 ポカヨケ（原則 3）

**-X 側の棚だけ 2.5 mm 高く、トレーの -X 側の下隅はそのぶん欠けている。**
向きを間違えると、低い方の棚に欠けていない縁が乗って 2.5 mm 浮き、
上の押さえに当たる。

**3 通りの反転（左右・前後・上下）を実際に回転させ、z を ±6 mm 総当たりして
ブーリアンで必ず当たること**をテストにした。さらに**対照実験**として
「段違いを消すと左右反転が座ってしまう」ことも押さえてある
（ポカヨケの根拠が段違いであることの裏取り。ここが落ちなくなったら、
逆向きを止めているのは別の何かで、それを触った瞬間に黙って消える）。

## 3. ついでに見つかった不具合: レールが宣言と 66 mm ずれていた

```python
prof = cq.Workplane("YX").polyline(pts).close()
solid = prof.extrude(p["rail_z1"] - p["rail_z0"])
return solid.translate((0, 0, p["rail_z0"]))
```

**`"YX"` の法線は -Z。** extrude は法線方向に伸びるので、
`rail_z0` から **-Z へ** 66 mm 伸びていた。

```
宣言:  z 128 〜 194
実物:  z  62 〜 128     （実測してみるまで誰も気づかなかった）
```

**どのチェックにも掛からない。** 穴でもソリッド干渉でも薄肉でもなく、
たまたま Onyx（x -36〜-0.2）とレール（x ±37〜39）が x で 1 mm すれ違っていたので
`clearance` も鳴らなかった。`docs/lid-fastening.md` §8.1 の背面リムの件と同じ種類、
つまり **「宣言と実物がずれる」失敗**である。

作り直した受けについては、**実物の z をビルド結果から測って宣言と突き合わせる**
テストを足した（`test_body_rails_were_replaced_and_the_old_extrude_bug_is_gone`）。

## 4. 検討したが不採用

| 案 | なぜ落ちたか |
|---|---|
| **アリ溝を柱の間（z 146〜181）だけに短くする** | 端が無いので**乗せる方法が無い**。落とし込むにはアンダーカットを消すしかなく、それはもうアリ溝ではない |
| **アリ溝 + 落とし込みの窓（キーホール）** | 窓の長さ + 掛かり代 + 行程が 35.2 mm の窓に収まらない。Pi が 30 mm を使うので動かせるのは 5.2 mm |
| **トレーに柱の逃げスリットを開けて通す** | スリットは全長に要る -> 中央の板と側の耳が**どこでも繋がらない**。柱は y 3〜44 の全域を塞ぐので y で逃げることもできない |
| **柱を動かす / 減らす** | D-019 で決着済み。面圧（`seal`）が 21% -> 13.3% に落ちる |
| **Pi を縦に置いて幅を 30 mm にする** | 案D（`docs/layout-study.md`）の再検討になる。**Onyx と OTG の折り返しが決まっているので崩せない** |
| **側壁に付けず、前壁から柱を立てて支える** | 成立はする（トレーの z 範囲には柱が無いので x はどこでもよい）。**ただし棚を側壁から内側へ伸ばすだけで足りた**ので、部品を増やさない方を採った |
| **ねじ 1 本で留める** | 現地で工具が要る（原則 6）。トレーは蓋を開けたときにしか触らないので、クリックで足りる |

## 6. 実機で確かめること（計算では出せない）

1. **クリック止めの保持力。** 歯 0.8 mm x 45 度が +Y にどれだけ耐えるかは
   計算していない。**蓋を開けた状態で箱を傾けて、トレーが落ちないこと**を見る
2. **ガタ。** 上の押さえまでの遊びは 1.2 mm ある。風で揺れ続ける設置先なので、
   月単位で音が出るなら**薄いスポンジを 1 枚**挟むのが手っ取り早い
3. **M2.5 の下穴 φ2.1**（推定）。Pi の穴は φ2.75 なので、ねじが太すぎると入らない
4. **差し込みの感触。** 差し込み方向は造形の積層方向と平行（段差を横切る）。
   片側 0.4 mm（層厚 0.2 の 2 倍）の隙間で引っかからないはずだが、
   **手袋をした手で入るか**を見る
5. **OTG ケーブルの取り回し。** トレーを引き出すとき、ケーブルが突っ張らない
   長さがあるか。結束点は未設計
