**規格から引けるものは実測を待たずに確定させた。**（D-024 / D-026）

| 宿題 | 元の状態 | いま |
|---|---|---|
| **A** FFC の曲げ | 実測待ち | **解決**（実測 1.165。幅 88 は動かない） |
| **B** ナットの二面幅 | 実測待ち | **実測 4.7 が入った**（トレーのポケットは未反映。§5） |
| **C** インサート外径 | 実測待ち | **解決**（M4 5.9 / M5 6.9 -> 下穴 5.4 / 6.4。D-024） |
| **D** 捕捉リテーナ | 実測待ち | **解決。ナイロンナットに確定**（D-026） |
| **E** 蝶ボルトの頭 | 実測待ち | **買うときの上限に変換した**（下記） |

### ★ 買うときに必ずノギスを当てるもの（1 つだけ）

**蝶ボルトの「首下の座の径」**（つまみの下の丸い座）。

```
M4:  座の径 10.0 mm 以下   （設計値 9.0。10.0 まではハーネスが通ることを確認済み）
M5:  座の径 11.5 mm 以下   （設計値 10.5。11.5 まで確認済み）
```

**11.0 / 13.0 まで大きいと `layout` が落ちる**ので、これは実際の上限である。
JIS B 1184 は「メーカーにより形状・寸法が若干異なる」と明記しているため、
**規格だけでは決め切れない。現物で確認するのが正しい。**
2種 R（小形）はおおむね収まる見込み。**H（大形）は外れる可能性がある。**

**ノギスを持って行くこと。** これ 1 つのために持つ価値がある。

## 5. この BOM に**入れていない**もの（理由つき）

- **ドーム蓋**: 在庫が大量にある（§3）
- **E 形止め輪 / 押しナット**: **不採用**。E 形は軸に溝を削る必要があり旋盤が無い、
  押しナットは外径が大きく蓋の肉が 0.286 mm まで落ちる。詳細は **D-026**
- **液体ねじロック剤**: **不採用**。現地で何度も開け閉めするので、
  再締結のたびに効きが落ちる。ナイロンナットに置き換えた（D-026）
- **トレーのナットポケット用のナット**: **Pi 側に既に付いている**
  （レスキューブラケットの取付ナット。`parts/pi_zero_2w_rescue`）。買う必要は無い。
  ただし**二面幅の実測 4.7 がまだ設計に入っていない**（推定 5.0 のまま）。
  **これは印刷前に反映すること**（`pcb_tray.PARAMS["nut_bore"]`）
- **ドームの取付ボルト 3 本**: `window_snoot.py` が**まだ確定していない**
  （ドーム嵌合の ①② が再測定待ち。D-025）。**確定したらこの表に足す**
