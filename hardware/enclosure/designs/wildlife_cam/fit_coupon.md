# fit_coupon — 実測結果と補正値の導出

このクーポンは「以降の全設計が使う嵌合公差テーブル」を 1 回の印刷で確定させる
ための治具。**v1 は 2026-08-22 に実際に印刷して測り終えている。**
その結果から起こした補正テーブルが `harness/fit.py` の
`asa-p1s-0.4mm-2026-08-22` で、以降の設計はすべてこれを通る。

この文書は 2 つの役目を持つ。

1. **実測値と、そこから補正値をどう導いたかの記録**（下記 1〜4 章）
2. **別の材料・条件で刷り直すときの手順書**（5 章。手順を再現できるように）

---

## 1. 印刷条件（実施済み）

**補正値はこの条件の組にしか意味がない。** どれか 1 つでも変えたら測り直すこと。

| 項目 | 値 |
|---|---|
| プリンタ | Bambu Lab P1S |
| 材料 | ASA |
| ノズル径 | 0.4 mm |
| 層厚 | 0.2 mm |
| 造形姿勢 | 平置き（`PRINT_ORIENTATION = (0,0,0)`） |
| 実施日 | 2026-08-22 |
| 対象 | `designs/wildlife_cam/fit_coupon.py`（v1・補正なし） |

v1 は補正を入れる前の素の形状（`FIT_TABLE = fit.NONE`）。補正値を決めるための
クーポンなので当然で、**v1 のファイルは実物の記録として凍結してある。**

## 2. 実測結果（生値）

測定はノギス。誤差 = 実測 − 設計。

### 2.1 薄板（垂直フィン）

| 刻印 | 設計 | 実測 | 誤差 |
|---|---|---|---|
| `0.8` | 0.80 | **0.80** | 0.00 |
| `1.2` | 1.20 | **1.20** | 0.00 |
| `1.6` | 1.60 | **1.60** | 0.00 |
| `2.0` | 2.00 | **2.00** | 0.00 |

4 点とも完全一致。0.8 mm（押出 2 本ぶん）も欠けずに出た。

### 2.2 軸穴（φ10 帯）

| 刻印 | 設計 | 実測 | 誤差 |
|---|---|---|---|
| `10.1` | 10.10 | **9.80** | −0.30 |
| `10.2` | 10.20 | **9.90** | −0.30 |
| `10.3` | 10.30 | **10.00** | −0.30 |
| `10.4` | 10.40 | **10.10** | −0.30 |

**4 点とも誤差が −0.30 で完全に一定。** 刻み（0.1 ずつ）も設計と一致している。
系統誤差であってばらつきではない、と読める。この帯は信頼度が高い。

### 2.3 基準ピン（外形の突起）

| 刻印 | 設計 | 実測 | 採用 | 誤差 |
|---|---|---|---|---|
| `10.0` | 10.00 | 9.7 〜 9.8（複数回） | **9.75** | −0.25 |

実測点は 1 種類だけ。

### 2.4 小穴

| 刻印 | 設計 | 実測 | 誤差 |
|---|---|---|---|
| `4.0` | 4.00 | 3.90 | −0.10 |
| `4.2` | 4.20 | 4.10 | −0.10 |
| `4.4` | 4.40 | 4.30 | −0.10 |
| `3.2` | 3.20 | 3.00 | −0.20 |
| `3.4` | 3.40 | 3.10 | −0.30 |
| `3.6` | 3.60 | 3.40 | −0.20 |

**小径の内径はノギスでの読み取り確度が低い。** ジョウの先端だけが当たるので
当てる角度で 0.1 mm 動く。この帯の値は暫定として扱う。

### 2.5 ヒートセット下穴

3 種（φ4.0 / 4.2 / 4.4・深さ 6 mm）とも**貫通していない**。設計どおり。

ただし**どの下穴が正解かはまだ決まっていない。** インサートの実物がまだ無く、
圧入して確かめていないため。`parts/m3_heatset.py` の `PILOT_DIA` は推定のまま。

### 2.6 O リング溝

**測っていない。** 溝幅・溝深さの実測がないので、補正テーブルに溝の規則が無い。
v2 では測ること（設計側は `uncompensated()` で無補正のまま通し、
report に「無補正」として記録される）。

## 3. 補正値の導出

**補正 delta = −誤差。** 図面に足す量として持つ（狙い 10.1 に +0.30 して 10.4 と描く）。

### 3.1 壁 → **±0.00**

4 点とも誤差 0.00。補正不要。

### 3.2 穴・直径 8 mm 以上 → **+0.30**

誤差が 4 点とも −0.30 で一定。平均も最大も −0.30。迷う要素が無い。

```
delta = -(-0.30) = +0.30
```

### 3.3 穴・直径 2 〜 5 mm → **+0.25（暫定）**

誤差がばらつく（−0.10 〜 −0.30）。統計は次のとおり。

```
平均誤差 = -(0.10 + 0.10 + 0.10 + 0.20 + 0.30 + 0.20) / 6 = -0.167
最大誤差 = -0.30   （3.4 の 1 点のみ）
最小誤差 = -0.10   （4.x の 3 点）
```

採用値 **+0.25** は平均 0.167 と最大 0.30 の間で、最大寄り。理由:

- この帯の主用途は **M3 の通し穴（クリアランス穴）**。きつくなる側の失敗
  （ねじが通らない）より、緩くなる側の失敗（ガタが増える）の方が軽い。
  だから小さめの補正（平均 0.167）ではなく大きめに寄せた。
- 最大誤差 −0.30 は `3.4` の 1 点だけで、隣の `3.2`・`3.6` は −0.20。
  ノギスの読みが疑わしいので、そこまでは寄せなかった。

**この値は暫定。** v2 ではピンゲージかドリル刃で測り直して詰めること。

### 3.4 外形の突起 → **+0.25**

基準ピン 1 点のみ（誤差 −0.25）。

```
delta = -(-0.25) = +0.25
```

実測点が 1 種類しかないので、径による変化は分かっていない。

### 3.5 観察: 壁だけ誤差が出ないのはなぜか（仮説）

穴は −0.30（**片側 0.15**）、突起は −0.25（**片側 0.125**）小さく出た。
どちらも「輪郭が内側に 0.13 〜 0.15 mm 寄っている」と読める。一方、薄板は
誤差ゼロだった。薄板の厚みは輪郭位置ではなく**押出幅**で決まるので、
輪郭の寄りの影響を受けない — と考えれば説明がつく。

**これは仮説であって検証していない。** 補正値は実測から直接起こしてあり、
この解釈には依存していない。

### 3.6 未解決（テーブルの穴）

| 範囲・種類 | 状態 |
|---|---|
| 穴 φ5 〜 φ8 | **実測点が無い。** テーブルは隣の帯から外挿し、report に「外挿」と出る |
| 穴 φ2 未満 | 同上 |
| 溝幅・溝深さ | **規則が無い。** `uncompensated()` で通す |
| 角穴・ポケット | 同上 |
| 突起の径依存 | 実測点 1 つのみ |

## 4. できあがった補正テーブル

`harness/fit.py` の `ASA_P1S`（id: `asa-p1s-0.4mm-2026-08-22`）。

| 種類 | 範囲 | delta | 実測点 | 備考 |
|---|---|---|---|---|
| `wall` | 全域 | **+0.00** | 4 | 補正不要 |
| `hole` | φ8.0 以上 | **+0.30** | 4 | 誤差が一定。信頼度が高い |
| `hole` | φ2.0 〜 5.0 | **+0.25** | 6 | **暫定** |
| `boss` | 全域 | **+0.25** | 1 | 実測点は 1 種類のみ |

設計側からの使い方（`docs/AGENTS.md` §3.5 に規約がある）:

```python
from harness import fit
FIT_TABLE = fit.ASA_P1S

def build(p=PARAMS):
    f = FIT_TABLE
    cq.Workplane("XY").circle(f.hole(p["shaft_dia"]) / 2)   # 狙い 10.1 -> 図面 10.4
```

**PARAMS には狙い寸法だけを書く。設計者が式の中で 0.3 を足し引きしない。**

## 5. 別の材料・条件で刷り直すときの手順

新しい材料（PETG、ASA-CF、別ロットの ASA など）や別のノズル径に移るときは、
この手順をなぞれば同じ形のテーブルが作れる。

### 5.1 刷る

```bash
uv run python -m harness check designs/wildlife_cam/fit_coupon_v2.py
# out/fit_coupon_v2/fit_coupon_v2.3mf を Bambu Studio に読み込む
```

サポートは不要（overhang チェックで確認済み）。

> **v2 を使うこと。** v2 は基準ピンが折り取り式で、同じ板の軸穴に挿して
> 確かめられる。v1 はピンが台座と一体で生えていて挿せなかった（設計ミス）。
>
> v2 はすでに `asa-p1s-0.4mm-2026-08-22` の補正が入っている。**別材料で使うときは
> `FIT_TABLE = fit.NONE` に一時的に差し替えて、素の形状で刷ること。**
> 補正の入った形を測ると、測っているのが材料の癖なのか補正の効きなのか
> 分からなくなる。

### 5.2 印刷条件を記録する

| 項目 | 値 |
|---|---|
| プリンタ | |
| 材料 / メーカー / ロット | |
| ノズル径 | |
| 層厚 | |
| 壁ループ数 | |
| 充填率 | |
| ノズル温度 / ベッド温度 | |
| 造形姿勢 | |
| 印刷日 | |

### 5.3 測る

台座は 120 x 90 x 8 mm、全高 20 mm。刻印でどのフィーチャか分かる。

| 群 | 位置 | 刻印 | 中身 |
|---|---|---|---|
| A | 上段 左 | `4.0` `4.2` `4.4` | M3 ヒートセット下穴（深さ 6 mm の止まり穴） |
| B | 上段 右 | `3.2` `3.4` `3.6` | M3 通し穴 |
| C | 中段 左 | `10.1` `10.2` `10.3` `10.4` | 軸穴（通し） |
| C' | 中段 右 | `10.0` | **折り取り式の基準ピン**（v2） |
| D | 下段 左 | `0.8` `1.2` `1.6` `2.0` | 薄板（垂直フィン、高さ 12 mm） |
| E | 下段 右 | `OR20` | O リング溝（中心径 30 / 幅 2.70 / 深さ 1.50） |

順序:

1. **素の寸法**（台座 120.00 / 90.00 / 8.00）を測る。XY と Z で差が違うはず。
2. **D 薄板**をマイクロメータで。設計との差が「壁の補正」。
3. **C' 基準ピンを折り取る。** タブ 2 本（1.5 x 0.8 mm）を手で折る。
   折り跡は z = 0 〜 0.8 にしか無いので、測るのは z = 2 〜 14 の範囲。
   複数の高さで測って採用値を決める。設計との差が「突起の補正」。
4. **C 軸穴**を測る。さらに **折り取ったピンを実際に挿して**、圧入 / 摺動 / ガタを
   記録する（v1 ではこれができなかった）。設計との差が「φ8 以上の穴の補正」。
5. **B M3 通し穴**を測る。M3 ねじを実際に通す。設計との差が「小穴の補正（暫定）」。
6. **A ヒートセット下穴**にインサートを圧入し、一番きれいに入った穴径を採用する。
   - 樹脂が盛り上がって溢れる → 穴が小さい
   - 斜めに沈む / 手で回る → 穴が大きい
   - 面一で止まり、M3 を締めても供回りしない → 正解
7. **E O リング溝**の幅と深さを測る（v1 では測っていない）。φ2.0 コードを入れて
   平面で押さえ、はみ出さずに収まるか見る。

### 5.4 テーブルを起こす

各群について `delta = -(実測 - 設計)` を出し、`harness/fit.py` に `FitTable` を
追加する。**id には材料・機種・ノズル径・実測日を入れること。**

```python
PETG_P1S = FitTable(
    id="petg-p1s-0.4mm-YYYY-MM-DD",
    material="PETG", printer="Bambu Lab P1S",
    nozzle_mm=0.4, layer_mm=0.2, orientation="平置き",
    measured_on="YYYY-MM-DD",
    source="designs/wildlife_cam/fit_coupon.md",
    rules=(
        Rule(kind=WALL, lo=0.0, hi=math.inf, delta=..., samples=4, note="..."),
        ...
    ),
)
```

ばらつく帯は `provisional=True` を立てる。実測点が無い帯は**規則を作らない**
（テーブルが黙って外挿し、report に「外挿」と出る）。

### 5.5 反映して回し直す

```bash
uv run python -m harness check designs/wildlife_cam/pir_bezel.py
uv run pytest -q
```

各設計の `FIT_TABLE` を新しいテーブルに差し替え、`report.md` の `fit` セクションで
狙い寸法と図面寸法の対応を確認する。

## 6. v1 の設計ミスと v2 での修正

**v1 では基準ピン φ10.0 が台座と一体で生えていた。** そのため
「同じ板の軸穴に挿して嵌合を確かめる」ことが**物理的にできなかった**。
クーポンの目的の半分が達成できていない。

v2 ではピンを台座から独立させ、台座を貫く φ18.0 のソケット穴の中に立てて、
底の細いタブ 2 本（1.5 x 0.8 mm・合計断面 2.4 mm2）だけで繋いだ。
手で折り取れば自由なピンになり、そのまま隣の軸穴に挿せる。

- タブは第 1 層側（z = 0 〜 0.8）にしか無いので、測定に使う高さに折り跡が残らない
- ピンはビルドプレートに直接立つので、下向きの張り出しが出ない
- ピンの軸は軸穴と同じく造形方向に平行。**同じ向きで刷ったもの同士**を
  嵌合させるので比較に意味がある

## 7. 既知の限界

- このクーポンは **1 姿勢・1 材料・1 条件** の値しか出さない。
- 収縮は部品サイズに依存する。120 mm の台座で測った値を 20 mm の部品に
  そのまま当てると外す。
- 軸穴の基準が印刷ピンなので、値は「印刷品どうしの嵌合」であって
  金属軸に対する嵌合ではない。金属軸で使うなら φ10.00 の丸棒（ドリルシャンク等）で
  測り直すこと。
- テーブルには φ5 〜 φ8 の穴、溝、角ポケットの規則が無い（3.6 参照）。
