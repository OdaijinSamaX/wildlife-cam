# fit_coupon — 印刷したあとにやること

このクーポンは「以降の全設計が使う嵌合公差テーブル」を 1 回の印刷で確定させる
ための治具。印刷して測って、この文書の末尾の **FIT テーブル** を埋める。
埋めた値は `parts/` と `designs/` の `PARAMS` に反映する。

## 0. 印刷条件（必ず記録する）

以降の設計はこの条件で刷ることを前提にする。条件を変えたら測り直す。

| 項目 | 値 | 記入 |
|---|---|---|
| プリンタ | Bambu Lab P1S | |
| 材料 / メーカー / ロット | ASA / | |
| ノズル径 | 0.4 mm | |
| 層厚 | 0.2 mm | |
| 壁ループ数 | 4 | |
| 充填率 | 20% | |
| ノズル温度 / ベッド温度 | | |
| 造形姿勢 | 平置き（`PRINT_ORIENTATION = (0,0,0)`）| |
| 印刷日 | | |

```bash
uv run python -m harness check designs/wildlife_cam/fit_coupon.py
# out/fit_coupon/fit_coupon.3mf を Bambu Studio に読み込む
```

サポートは不要（overhang チェックで確認済み）。

## 1. クーポンの読み方

上面（刻印のある側）を手前にして、以下の 5 群が並んでいる。
どの数字がどのフィーチャかは刻印で分かる。

| 群 | 位置 | 刻印 | 中身 |
|---|---|---|---|
| A | 上段 左 | `4.0` `4.2` `4.4` | M3 ヒートセット下穴（深さ 6 mm の止まり穴） |
| B | 上段 右 | `3.2` `3.4` `3.6` | M3 通し穴 |
| C | 中段 | `10.1` `10.2` `10.3` `10.4` | 軸穴（通し） |
| C' | 中段 右端 | `10.0` | 基準軸（φ10.0 の立ちピン、高さ 12 mm） |
| D | 下段 左 | `0.8` `1.2` `1.6` `2.0` | 薄板（垂直フィン、高さ 12 mm） |
| E | 下段 右 | `OR20` | O リング溝（中心径 30 / 幅 2.70 / 深さ 1.50） |

表題は `FIT COUPON v1`。

## 2. 測る順序

### 2.1 まず素の寸法を測る（収縮率が出る）

| 測るところ | 設計値 | 実測 | 差 |
|---|---|---|---|
| 台座の長辺 | 100.00 mm | | |
| 台座の短辺 | 70.00 mm | | |
| 台座の厚み | 8.00 mm | | |
| 基準ピン外径 `10.0` | 10.00 mm | | |
| 基準ピン高さ | 12.00 mm | | |

XY と Z で差が違うはず。ここで出た差は他の全ての測定値に効く。

### 2.2 A: ヒートセット下穴

M3 インサート（想定 OD 4.6 / L5.0）をはんだごてで圧入し、**一番きれいに入った
穴径**を採用する。判定基準:

- 樹脂が盛り上がって溢れる → 穴が小さい
- インサートが斜めに沈む / 手で回る → 穴が大きい
- 表面と面一で止まり、M3 ねじを締めても供回りしない → **正解**

圧入後に M3 ねじをねじ込み、トルクを掛けて抜けないことを確認する。

| 刻印 | 設計値 | 実測穴径 | 圧入の所感 | 採用 |
|---|---|---|---|---|
| `4.0` | φ4.00 | | | |
| `4.2` | φ4.20 | | | |
| `4.4` | φ4.40 | | | |

### 2.3 B: M3 通し穴

M3 ねじ（呼び径 3.0）をスムーズに通し、かつガタが最小の穴を採用する。

| 刻印 | 設計値 | 実測穴径 | ねじの通り | 採用 |
|---|---|---|---|---|
| `3.2` | φ3.20 | | | |
| `3.4` | φ3.40 | | | |
| `3.6` | φ3.60 | | | |

### 2.4 C: 軸穴嵌合

**基準は φ10.0 の丸棒**（ドリルのシャンク、真鍮丸棒など、実測して 10.00 ±0.02 の
もの）。無ければ同じクーポンに立っている `10.0` の印刷ピンを使うが、その場合は
「印刷品どうしの嵌合」の値になるので、テーブルにそう書くこと。

| 刻印 | 設計値 | 実測穴径 | 嵌合の所感（圧入 / 摺動 / ガタ） | 用途 |
|---|---|---|---|---|
| `10.1` | φ10.10 | | | |
| `10.2` | φ10.20 | | | |
| `10.3` | φ10.30 | | | |
| `10.4` | φ10.40 | | | |

用途の目安: 圧入 = 抜け止め不要の固定、摺動 = 手で回る軸受、ガタ = ケーブル通し。

### 2.5 D: 薄板の実効肉厚

マイクロメータで各フィンの厚みを測る。設計値との差が「壁の太り」。

| 刻印 | 設計値 | 実測 | 差 | 目視（隙間・積層の欠け） |
|---|---|---|---|---|
| `0.8` | 0.80 mm | | | |
| `1.2` | 1.20 mm | | | |
| `1.6` | 1.60 mm | | | |
| `2.0` | 2.00 mm | | | |

0.8 mm は 0.4 mm ノズルの押出 2 本ぶんなので、**刷れていない／隙間が透ける**ことが
ありうる。それが分かれば十分（`min_wall_mm = 1.6` の根拠が実測で裏付けられる）。

### 2.6 E: O リング溝

φ2.0 の O リングコードを溝に入れ、ガラス板などの平面で押さえて潰れ具合を見る。

| 項目 | 設計値 | 実測 |
|---|---|---|
| 溝幅 | 2.70 mm | |
| 溝深さ | 1.50 mm | |
| 溝の中心径 | 30.00 mm | |
| コードがはみ出す / 収まる | 収まる | |

設計の根拠（`parts/oring.py`）: 圧縮率 25%、充填率 78%。
溝が浅く出た場合は圧縮率が上がり、O リングが逃げ場を失って切れる。深さの実測が
1.5 mm を下回ったら、次版で溝深さを +0.05 〜 +0.1 mm する。

## 3. FIT テーブル（これを埋めて設計に反映する）

埋めたらこの表を `docs/` に切り出すか、`parts/` の各モジュールに書き戻す。

```
印刷条件: P1S / ASA / 0.4 nozzle / 0.2 layer / 4 walls / 実施日 ____-__-__

FIT_M3_HEATSET_PILOT_DIA = ____   # -> parts/m3_heatset.py PILOT_DIA
FIT_M3_CLEARANCE_DIA     = ____   # -> designs/*/PARAMS screw_dia
FIT_SHAFT_PRESS_DIA      = ____   # 圧入になった穴径
FIT_SHAFT_SLIDE_DIA      = ____   # 摺動になった穴径
FIT_WALL_MIN_PRINTABLE   = ____   # 実際に刷れた最小肉厚
FIT_XY_SHRINK            = ____   # (実測 - 設計) / 設計   XY 方向
FIT_Z_SHRINK             = ____   # 同 Z 方向
FIT_ORING_GROOVE_DEPTH   = ____   # 実測した溝深さ
```

反映先:

| 値 | 反映先 |
|---|---|
| `FIT_M3_HEATSET_PILOT_DIA` | `parts/m3_heatset.py` の `PILOT_DIA`、`DIM_SOURCE` を `measured:YYYY-MM-DD` に |
| `FIT_M3_CLEARANCE_DIA` | `designs/wildlife_cam/pir_bezel.py` の `screw_dia` |
| `FIT_WALL_MIN_PRINTABLE` | `docs/AGENTS.md` の最小肉厚の根拠 |
| `FIT_ORING_GROOVE_DEPTH` | `parts/oring.py` の `GROOVE_DEPTH` |

反映したら、その部品を使っている全ての設計で

```bash
uv run python -m harness check designs/wildlife_cam/pir_bezel.py
uv run pytest -q
```

を回し直すこと。

## 4. 既知の限界

- このクーポンは **1 姿勢・1 材料・1 条件** の値しか出さない。姿勢や材料を変えたら
  測り直しが要る。
- 収縮は部品サイズに依存する。100 mm の台座で測った収縮率を 20 mm の部品に
  そのまま当てると外す。
- 軸穴の基準が印刷ピンだった場合、値は「印刷品どうしの嵌合」であって、
  金属軸に対する嵌合ではない。
